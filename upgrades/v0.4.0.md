# Upgrade to v0.4.0

## Both machines

```
# stop the scheduled sync first (Task Scheduler: Disable; see docs/updating.md)
git pull
# requirements.txt is unchanged (notion-api v1.1.1); confirm the installed client
venv\Scripts\python -c "import notion_api; print(notion_api.__version__)"
# run once by hand and read the log
venv\Scripts\python sync.py
# re-enable the scheduled sync
```

## Config (config.toml)

```toml
# rename in every [[databases]] block (the old `id` still works, with a warning)
database_id = "your-database-id-here"

[output]
# optional: write a consistent copy after every run for another machine to fetch
# snapshot_dir = ""

# optional: raise if Notion resets connections during content fetches

```

## Behavior changes

```
# sync.py now exits 1 when any database fails to sync (it used to exit 0).
#   Task Scheduler "Last Run Result" 1 now means a database failed; read the log.
# New columns deleted_at, delete_state, moved_to are added to every *_pages table on the first run (automatic).
# Schema tracking now honors include_columns / exclude_columns (fixes the crash on excluded properties).
# New: sync.py --detect-deleted, tools/db_snapshot.py, tools/check_freshness.py (docs/ folder).
```
