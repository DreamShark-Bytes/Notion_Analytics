# Upgrade to v0.1.1

Rename this file to `v0.2.0.md` if the version is bumped before tagging.

## Both machines

```
git pull
```

Optional (only if new packages added — check release notes):
```
# Linux
venv/bin/pip install -r requirements.txt

# Windows
venv\Scripts\pip install -r requirements.txt
```

## Run date migration

```
# Linux
venv/bin/python tools/split_date_columns.py --all-dates --exclude period_key_recurring_task due_date_sort --column closed_date --dry-run
venv/bin/python tools/split_date_columns.py --all-dates --exclude period_key_recurring_task due_date_sort --column closed_date

# Windows
venv\Scripts\python tools\split_date_columns.py --all-dates --exclude period_key_recurring_task due_date_sort --column closed_date --dry-run
venv\Scripts\python tools\split_date_columns.py --all-dates --exclude period_key_recurring_task due_date_sort --column closed_date
```

## Run sync

```
# Linux
venv/bin/python sync.py

# Windows
venv\Scripts\python sync.py
```

Check log for:
- `_schema` and `_options` tables populated
- WARNING about `effort_level` orphaned column
- No spurious change events

## Remove orphaned columns

```
# Linux
venv/bin/python tools/cleanup_orphaned_columns.py

# Windows
venv\Scripts\python tools\cleanup_orphaned_columns.py
```

Answer Y when prompted for `effort_level`.

## ThinkPad only

Stop before starting: right-click `Notion Analytics Sync` in Task Scheduler → **Disable**

Re-enable after sync verified: right-click → **Enable**
