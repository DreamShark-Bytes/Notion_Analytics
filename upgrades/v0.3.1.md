## Config update (optional)

If you have `include_content = true` on any database with a large number of pages,
add the following to the `[output]` section of `config.toml` to prevent
Notion's API from closing the connection during full syncs:

```toml
[output]
content_fetch_delay_ms = 200
```

No code migration needed.
