# Upgrade to v0.3.0

## Both machines

```
git pull
```

## Run sync

No migration needed — the `_meta` table is created automatically on first sync after updating.

```
# Linux
venv/bin/python sync.py

# Windows
venv\Scripts\python sync.py
```

Check log for:
- `Full sync (no prior timestamp)` — expected on first run after upgrade
- Subsequent runs should show `Incremental sync from ...` and complete in seconds
